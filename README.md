# Glühwürmchen-Nacht

Ein kleines Nachtspiel im Browser: Fang Glühwürmchen mit dem Glas, weich Motten, Fledermäusen, Spinnen, der Mottenkönigin und dem Waldkauz aus.

Einfach `index.html` im Browser öffnen – keine Installation, keine Abhängigkeiten.

## Inhalt

- **Modi:** Normal, Geschichte (10 Kapitel mit bis zu 3 Sternen), Zen, Tagesnacht (gleiche Abfolge für alle an einem Tag), Sturm, Zu zweit (lokal, zwei Gläser)
- **Nach jeder Nacht** eine Verbesserung wählen (15 verschiedene)
- **Gewitter, Nebel, Schwärme, zwei Bosse**
- **Naturbuch** mit echten Fakten über Leuchtkäfer und ihre Nachbarn
- **Echte Mondphase** des heutigen Tages am Himmel (mit kleinem Spielbonus bei Voll- und Neumond)
- 27 Erfolge, 8 Glas-Designs, lokale Bestenliste, Aufträge
- Deutsch und Englisch umschaltbar
- Auf dem Handy installierbar („Zum Startbildschirm hinzufügen“) und nach dem ersten Besuch auch offline spielbar (über GitHub Pages bzw. HTTPS)

## Steuerung

- Maus, Finger oder ← → / A D bewegen das Glas
- Leertaste oder Doppeltipp: Sprint
- P oder Esc: Pause
- Controller: Stick bewegt, A sprintet, Start pausiert
- Zu zweit: Spieler 1 A/D + W, Spieler 2 ← → + ↑

## Hinweis

Fortschritt, Rekorde und Einstellungen werden im Browser gespeichert (`localStorage`).
Die gemeinsame Bestenliste und die Anzeige „Gerade auf der Wiese“ funktionieren nur in der claude.ai-Version des Spiels; hier werden sie einfach ausgeblendet.
